02 / RIGHT AT HOME

A native window.
A familiar feeling.

Four-zone colors and effects. CoolBoost. CPU and NVIDIA GPU monitoring. Local profiles, history export and a system tray. Built around the original layout, using native Qt controls.

It started with one AN515-45, a Windows installer, and four years of wanting the controls back. The result is an independent Linux reconstruction, with the protocol findings and hardware tests published alongside the code.

03 / MAKE YOURSELF AT HOME

Start with the app.
Then the driver.

Python 3.10+ and PySide6. Launch as your normal user. Hardware controls use a separately installed driver and a narrow access group.

The source release includes driver setup, removal and recovery instructions. Kernel headers must match your running kernel.

Read the installation guide ↗
TERMINAL / SOURCE INSTALL
git clone https://github.com/Dahuum/nitro-sense-linux.git
cd nitro-sense-linux
python -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/nitro-sense

Opening the app and importing a profile do not apply hardware settings. Use --read-only to explore with changes disabled.

Your fans should always have a way back.

Normal exit and handled termination request Auto. A killed process, missing driver or hardware failure can prevent that. Keep the recovery instructions handy. This initial release doesn’t claim complete Windows UI, audio or accessibility parity.
